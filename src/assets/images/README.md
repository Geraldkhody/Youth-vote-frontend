# Images

Put real photos here, for example a parish or past-event photo for the hero
section of the home page.

The home page works with no photo at all — it falls back to the inline SVG
hero illustration in `src/components/illustrations/HeroIllustration.tsx`. If a
photo is added later, reference it from `src/pages/HomePage.tsx` and keep the
illustration as a fallback for when no photo is configured.

Suggested filename: `hero.jpg`.
