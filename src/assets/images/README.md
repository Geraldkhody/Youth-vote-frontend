# Images

Put real photos here, for example an organiser or past-event photo for the
hero section of the home page.

The home page works with no photo at all — it falls back to the inline SVG
hero illustration in `src/components/illustrations/HeroIllustration/HeroIllustration.tsx`.
If a photo is added later, reference it from `src/pages/HomePage/HomePage.tsx`
(there is a marked comment in the hero section) and keep the illustration as
a fallback for when no photo file is present.

Suggested filename: `hero.jpg`.

## Before you add a photo

- Only use photos the parish or event owns, or has written permission to publish.
- Get consent from everyone who is identifiable in a photo before publishing it, and always get consent from a parent or guardian for anyone under 18.
- When in doubt, leave the photo out — the site is designed to look complete without one.
